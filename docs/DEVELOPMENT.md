# 开发与验证

## 目录

```text
zhihuishu-review-memory.user.js  可安装构建产物
src/review-memory.js            解析、匹配、选择核验与列表顺序流程
src/learn-navigation.js         学习页目录、入口与掌握度前进流程
scripts/build.py               将增强模块注入固定上游代码
tests/behavior.cjs             jsdom 行为回归测试
vendor/upstream-1.0.3.js        未改动的上游基础脚本
vendor/UPSTREAM.json           上游来源与内容指纹
docs/                         使用与开发文档
```

当前构建器基于固定文本集成点进行替换，不是通用 JavaScript 打包器。上游代码变化可能使集成点数量断言失败；不要直接把 vendor 文件换成上游最新版本再忽略这些断言。

## 环境与命令

使用 Python 3.10+、Node.js 24.15+（24.x）或 26+。Node 版本要求来自锁定的 jsdom 测试依赖；安装用户脚本本身不需要这两个运行时。

```sh
npm ci
npm run build
npm run check
npm test
```

Windows 上如果 Python 命令名是 `py`，可以用 `py scripts/build.py` 代替 `npm run build`。CI 使用 Node 24 与 Python 3.12。

构建产物应与提交的根目录 `.user.js` 一致；提交前执行构建、测试，再检查差异。主要修改放在 `src/`；保留 vendor 原文件便于追溯上游。

## 测试覆盖与边界

本地已有 131 项行为回归，覆盖：

- 参考答案与学生作答区分、题目乱序、选项重排和多选集合对应。
- 数学符号及变量大小写保留，公式 URL 变化后的内容指纹核验。
- DOM 替换、字体图标、ARIA / 原生控件状态、停止后的行为约束。
- 空历史、解析页整页读取、延迟加载与内层滚动。
- 填空跳过、已保存顺序队列、学习页目录与备用练习历史入口。
- 达到阈值优先前进，以及历史页已达标、学习页仍显示旧数值的情况。

测试使用合成编号与模拟 DOM，不连接真实登录账户、不调用付费 AI、不抓取真实题库，也不运行真实截图渲染。因此不能证明所有课程布局、服务商兼容性、图像识别准确率或移动端兼容性。

发布前的人工验收应至少记录：脚本版本、浏览器、页面模式、练习开始、解析保存、答案命中、真实勾选、阈值跳过、填空跳过、跨模块前进和停止行为。请把结论写成观察结果，避免宣称“全课程可用”或“保证正确率”。

## 发布维护

1. 修改源码和对应行为回归。
2. 更新 `package.json`、构建脚本中的版本和诊断版本字段，维护 `CHANGELOG.md`。
3. 构建并测试，核对源码与产物版本一致。
4. 检查 diff 中没有个人配置、真实课程编号、Cookie、密钥或导出记录。
5. 提交到 `main`。README 的安装链接和脚本元数据固定指向根目录构建产物。

已有用户的脚本身份与存储需要谨慎处理。当前保留上游 namespace 以减少原条目升级时的识别变化；用户仍应在原条目内替换，而不是卸载重装。
