# 使用说明

## 第一次运行

1. 安装根目录用户脚本，启用 Tampermonkey，并关闭同类自动化脚本。
2. 登录课程，打开要开始的知识点学习页。学习页网址通常包含 `/learnPage/`。
3. 展开 ZHS 面板，打开设置，保存自己的 API 地址、密钥和模型名。
4. 选择「掌握度自适应」，默认阈值 90，点击「开始/继续」。

接口需要接受 `POST <Base URL>/chat/completions` 及 `messages` 格式。Base URL 不要再包含 `/chat/completions`。某些接口不接受脚本携带的关闭思考参数，出现 400 时需要检查服务商返回的错误详情。截图或图片题需要支持视觉输入的模型。

## 运行顺序

学习页模式会读取当前知识点的「知识点最高掌握度」，再决定动作：

| 条件 | 动作 |
| --- | --- |
| 达到阈值，默认 ≥90% | 清理该节遗留待处理状态，按目录进入下一知识点 |
| 未达标且尚未达到次数上限 | 进入该知识点练习；有待处理解析时优先读取解析 |
| 已标记含填空题 | 跳过当前整套练习，继续下一知识点 |
| 已达到 4 次尝试上限 | 继续下一知识点 |
| 未能唯一定位当前/下一知识点 | 保留位置并停止提示，避免回到前面或选错节 |
| 后续目录已处理完 | 停止，不绕回开头 |

学习页左侧目录会自动展开模块、知识单元并滚动扫描。脚本只操作页面提供的目录和练习入口；没有成功读取的内容不会被标记为完成。

列表模式按首次建立队列时的页面顺序，从手动起点向后处理。列表重排不会把已保存队列改为“从头挑低分”。若开始时尚未设置起点，则从可读取列表的第一项建立队列。为便于明确起点，推荐从具体学习页启动。

## 参考答案如何复用

解析页会保存题干、全部选项内容、平台公布的答案及来源信息。匹配时比较题目内容和完整选项集合，再把正确内容映射成当前显示的字母。题号、题目排序和原来的字母不会被当作可靠答案。

例如，某正确选项从旧解析的 B 移到当前的 D，脚本会按内容对应选择 D。多选会核对最终勾选的完整集合，并清掉原来残留的错误勾选。

题干中的公式图片可能每次使用不同 URL。脚本会尝试获取图片，核对实际内容指纹，首次读取可能较慢。图片未下载成功、选项残缺、参考答案冲突或多个答案无法唯一对应时会提示停止。AI 的猜测不会写成平台参考答案。

面板中的「参考答案 / AI / 拦截」用于区分本轮答案来源。点击停止后，不应继续勾选或导航；若已发出的网络请求无法立即取消，其返回结果也会受到后续停止检查。

## 菜单说明

通过浏览器工具栏中的 Tampermonkey 图标找到当前脚本菜单：

| 菜单 | 用途 |
| --- | --- |
| 顺序进度：查看 | 查看当前学习知识点或保存的顺序进度 |
| 顺序进度：清除并重新设起点 | 停止运行，清掉本次顺序位置与尝试状态，之后从目标知识点重新启动 |
| 填空跳过：查看标记 | 查看被整套跳过的知识点 |
| 填空跳过：清除标记 | 允许后续重新检查这些知识点 |
| 解析记忆：显示题库数量 | 查看本地已保存题目数量 |
| 解析记忆：重新读取本次解析 | 停留在解析页时重新扫描已公布答案 |
| 解析记忆：清空题库 | 清除参考答案；操作前有确认，不清除 API 配置 |
| 参考答案：导出使用记录 | 导出答案来源、对应关系、公式核验和导航记录 |
| 解析排查：导出页面结构 | 导出题目或学习页目录的结构样本 |
| 选项排查：导出选中状态 | 导出最后一次勾选确认的诊断记录 |

面板的「重置做题次数」是上游旧流程计数入口，不等于清除新版顺序队列。新版顺序流程达到尝试上限后要重新起步，请使用对应的「顺序进度」菜单。

## 升级

更新前先按停止。在原脚本条目里替换完整代码并保存，刷新学习页再开始。公开测试版的版本号与本地迭代版不同，本次公开版基于 `1.1.0-local.15`。如果重新创建了一个脚本条目，旧条目的存储不会自动迁移到新条目。

请先用一两个知识点观察答案来源、勾选与前进方向。遇到未知界面时参考 [故障排查](TROUBLESHOOTING.md)，不要把持续停止简单理解为模型准确率问题。
