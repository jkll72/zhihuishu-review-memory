# 数据、网络与权限

## 本地保存

脚本通过 Tampermonkey 的 `GM_getValue / GM_setValue` 保存 API 配置、已公布解析、公式图片指纹、顺序进度、尝试次数、填空跳过标记和诊断记录。存储属于当前脚本条目，配置会以可供脚本读取的形式存在，不能视为密钥保险库。

卸载脚本条目或清理脚本存储可能丢失这些数据。不要通过分享整个脚本存储来给别人分发题库。

## 网络去向

| 去向 | 数据与用途 |
| --- | --- |
| 你配置的 AI Base URL | 题干、选项、相关图片 URL / 图片数据或题目截图；请求使用你的 API Key |
| 题目中的原图片地址 | GET 下载公式图片，核对内容指纹；公式指纹下载不附带 AI Key |
| jsDelivr | 加载固定版本 `html2canvas-pro@2.5.3` 截图库 |
| GitHub Raw | Tampermonkey 检查、下载此脚本的后续版本 |
| 智慧树课程页面 | 通过页面点击或当前知识点对应的历史页地址进行导航 |

仓库维护者没有自建接收接口，脚本没有添加使用统计上报。用户配置的 AI 服务会如何保存和处理请求，需要查看该服务商的政策。

## 为什么有这些权限

- `GM_getValue / GM_setValue`：本地配置、解析和进度。
- `GM_registerMenuCommand`：导出诊断、查看进度、清理题库等菜单。
- `GM_xmlhttpRequest`：访问用户配置的 AI 接口及题目图片，支持跨域请求。
- `unsafeWindow`：与页面运行标记、停止状态及截图流程配合。
- `@connect *`：AI 地址由用户配置，题目图片也可能来自多个域名，当前未提供固定域名白名单。

`@connect *` 表示脚本具备较宽的请求范围。只在自己信任的脚本版本中填写密钥，安装前可审阅源码和构建脚本。

## 日志与导出

公开构建不在面板工具提示中展示 API Key 前缀，也移除了上游输出完整请求消息、请求体、原始响应、推理正文和图片 Base64 的默认调试输出。界面仍会显示与排查有关的题目、选项、模型标识、接口地址和错误信息。

导出使用记录与页面结构是用户手动触发的操作。输出可能包含题干、解析、课程/班级/知识点编号、图片地址、导航地址和页面 HTML，不应直接视为可公开数据。不要公开 API Key、Cookie、个人姓名或可以恢复登录状态的内容。

## 发布包内容

本仓库只分发脚本源码、固定上游代码、构建脚本、文档与测试。没有包含个人诊断 JSON、浏览器存储、真实课程编号、登录信息、API Key、个人截图或现成答案库。测试中的课程、班级和知识点编号为合成数据。
