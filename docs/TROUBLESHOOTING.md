# 故障排查

## 不显示面板

确认只启用了一个本项目脚本，页面域名在 README 的支持范围内。按 Tampermonkey 的提示允许用户脚本运行，保存脚本并刷新页面；面板可能折叠成 ZHS 按钮。其他脚本管理器和移动浏览器尚未验证。

## 学习页读取失败

日志会分别报告实际标题、掌握度和预期标题。等待页面加载完成后重试；如果仍失败，停留在该页，用「解析排查：导出页面结构」导出样本。

不要把 PDF 工具栏的 77% 缩放当作掌握度。脚本只应读取「知识点最高掌握度」对应的数值；读取到错误数字请在反馈中说明。

## 找不到去提升入口

公开版支持去掉图标文字后定位按钮，并短暂等待按钮出现。按钮无法识别或点击后仍留在原页时，会依据当前课程、班级和知识点编号打开对应的练习历史页。显式禁用的入口不会被绕过。

若备用地址也不适用于你的课程，请停止，导出「参考答案使用记录」和「页面结构」。记录会包含入口方式、当前知识点及导航地址，便于修正适配。

## 达标后仍重复当前节

当前版把达到阈值放在遗留待读状态之前处理，并按课程、班级、知识点编号保存确认过的最高掌握度。学习页暂时出现旧值时，已确认的历史页掌握度仍有效。

确认面板阈值是期望数值，并检查是否有另一个旧脚本同时运行。若仍重复，导出使用记录，附上当前页面显示的掌握度和日志；不要先清空记录，否则会丢掉定位原因所需的状态。

## 找不到下一节或回到前面

学习页会展开并滚动左侧目录；列表模式只处理可读取列表建立的队列。网络加载、虚拟滚动、目录名称重复或页面布局变化都可能影响定位。脚本无法唯一确认目标时会停止。

保留当前页，用「解析排查」导出目录结构，再附上预期下一节名称。需要手动换起点时，可使用「顺序进度：清除并重新设起点」。

## 全部转给 AI

先在解析页查看是否出现「已保存 N/N 道题」，再通过「解析记忆：显示题库数量」核对。常见原因包括：不同脚本条目的存储隔离、题目尚未读过解析、题干或选项确有变化、公式图片没有核验成功。

使用记录中会区分 `platform-review`、`ai`、`miss` 和 `blocked`。若已经读取解析却无法命中，请反馈脱敏后的使用记录。单纯调高模型规格不会修复内容对应错误。

## 单选状态未确认 / 实际勾选不一致

脚本会等待页面状态更新，并对单选目标重新定位重试一次；多选不会盲目重复切换。仍无法确认时，用「选项排查：导出选中状态」导出记录，附上当时实际选中的选项。界面选中外观与脚本读到的状态可能不同，不能直接跳过核验继续提交。

## 无法区分选项 / 公式核验失败

两个不同选项可能因公式没有加载而显示相同文本。先检查题面与图片是否完整。内容确实相同的选项无法安全映射，脚本会停止。公式图片下载超时可在网络恢复后重新读取解析；脚本不会直接忽略公式差异来套用答案。

## 填空题

当前不自动填写。识别到填空题会记录知识点并跳过整套练习，继续后续目录。清除该标记后也只是允许重新检查，不会让脚本突然具备填空能力。

## AI 接口错误

- `401/403`：检查密钥、授权、接口地址与服务商区域是否一致。
- `400`：阅读错误详情，检查模型名、图片输入和关闭思考参数的兼容性。
- `404`：检查 Base URL 是否重复包含接口路径、模型标识是否正确。
- 超时或额度错误：按服务商控制台状态处理。

截图/含图片题要使用接受图片输入的模型。具体模型列表和计费以服务商当前控制台为准，本项目不附带密钥或额度。

## 提交有效反馈

请提供版本号、浏览器与脚本管理器、运行模式、完整错误文字、预期行为和实际行为。优先使用仓库的 Bug 模板。

诊断 JSON 可能包含课程编号、题干、参考答案、图片 URL 或页面 HTML。发布前查看并脱敏；若不确定，应先只提供错误文字和局部截图。不要上传 Cookie、API Key、整页网络抓包或账户配置文件。
