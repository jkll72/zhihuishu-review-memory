# 智慧树掌握度 · 解析记忆与顺序练习

适用于智慧树「新形态课程 / AI 智慧课程」的 Tampermonkey 用户脚本。读取页面已经公布的参考答案，按题干和选项内容对应复用；从手动选择的知识点向后处理，达到掌握度阈值后进入下一节。

**当前版本：`1.1.1-beta.1`，公开测试版。** 基于本地迭代版 `1.1.0-local.15` 整理，包含 131 项浏览器 DOM 模拟行为测试。尚未完成覆盖多门课程的真实网页验收，平台布局变化时可能需要适配。

**[安装脚本](https://raw.githubusercontent.com/jkll72/zhihuishu-review-memory/main/zhihuishu-review-memory.user.js)** · [详细使用说明](docs/USAGE.md) · [常见问题](docs/TROUBLESHOOTING.md) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/jkll72/zhihuishu-review-memory/issues/new/choose)

## 能做什么

| 功能 | 当前行为 |
| --- | --- |
| 解析记忆 | 读取「参考答案 / 正确答案 / 标准答案」，保存到当前脚本的本地存储 |
| 顺序变化 | 按题干及完整选项内容对应，适应错题前置和选项重排 |
| 答案来源 | 优先使用能唯一匹配的已公布答案；新题未命中时调用用户配置的 AI |
| 题型 | 单选、多选、判断；遇到填空题标记并跳过整套练习 |
| 顺序前进 | 从当前起点向后处理；默认掌握度 **90% 及以上**进入下一节 |
| 练习上限 | 每个知识点最多尝试 4 次，之后继续后一个 |
| 学习页目录 | 展开模块及知识单元、滚动左侧目录，查找后续知识点 |
| 公式图片 | 下载图片并核对内容指纹，避免仅凭图片网址或相似文字套用答案 |
| 过程核验 | 核对实际勾选状态；停止按钮会阻止后续选择或导航 |

重复选项、残缺公式、答案冲突、无法唯一对应的题目会停止提示。页面未公布的答案不会被脚本直接从平台后台提取。AI 回答不保证正确，平台公布答案本身也可能有错误。

## 支持范围

脚本匹配以下域名：

- `ai-smart-course-student-pro.zhihuishu.com`
- `studentexamcomh5.zhihuishu.com`
- `examloop.zhihuishu.com`

主要增强并测试的是**掌握度自适应流程**，包括 `/learnPage/`、掌握度列表、练习历史和 `/examPreview/` 解析页。上游保留的「课后作业/测试」模式未做同等覆盖，不承诺具有相同的解析记忆与顺序导航行为。

本项目不包含课程答案库，不提供考试场景适配。请在你获准使用辅助工具的学习练习中使用，并遵守所在课程的要求。

## 安装

1. 在桌面版 Edge 或 Chrome 中安装 [Tampermonkey](https://www.tampermonkey.net/)。按照插件提示启用用户脚本权限。
2. 点击上方「安装脚本」，在 Tampermonkey 中确认安装。
3. 如果浏览器只显示源码，打开 Tampermonkey 管理面板 → 添加新脚本，将本仓库根目录 `zhihuishu-review-memory.user.js` 的完整内容粘贴进去并保存。
4. 关闭其他同类脚本，刷新课程页面。面板折叠时点击 **ZHS** 展开。

**已有本项目旧版的用户：优先在原脚本条目内替换代码保存。** 不要先卸载旧条目，否则旧条目保存的 API 配置、题库和进度可能丢失。

## 配置与开始

打开面板右上角 ⚙，填写自己的 AI 服务配置：

| 配置 | 填写方式 |
| --- | --- |
| API Base URL | 你所使用的 OpenAI 兼容接口基础地址；脚本会追加 `/chat/completions` |
| API Key | 在服务商控制台创建的个人密钥 |
| Model Name | 服务商实际开放的模型标识，含图片题时需要支持图片输入的模型 |
| Max Tokens | 默认 2048，可按服务商限制调整 |
| Timeout | 默认 120000 毫秒 |
| 掌握度阈值 | 默认 90；达到或超过此值前进 |

点击「保存配置」，选择「掌握度自适应」。打开希望作为起点的**知识点学习页**，点击「开始/继续」。脚本会按掌握度决定练习或前进，到后续目录末尾结束。列表模式以当前页面可读取的列表条目建立队列；学习页模式会展开并扫描左侧目录。界面未能加载的目录项不会被视为已经完成。

按「停止」可以中断。需要换起点时，打开目标知识点再开始；也可以通过 Tampermonkey 菜单「顺序进度：清除并重新设起点」清除本次进度后重新开始。

## 数据与权限

API 配置、解析题库、图片指纹、跳过标记及顺序进度使用 Tampermonkey 的 `GM_setValue` 保存。项目没有自建数据接收服务。

调用 AI 时，题干、选项、相关图片或题目截图会发送到**你配置的接口**；API Key 会用于该接口的请求授权。公式核验会向原图片地址请求数据。截图引擎由 jsDelivr 加载固定版本的 `html2canvas-pro`。这些行为及 `@connect *` 的原因见 [数据与权限说明](docs/PRIVACY.md)。

导出的排查记录包含题目内容、课程/知识点编号、图片网址和页面结构。公开反馈前请检查并移除个人信息，不要上传 API Key、Cookie 或完整登录抓包。

## 开发与验证

普通用户安装根目录 `.user.js` 即可，无需安装 Node.js 或 Python。

开发环境使用 **Python 3.10+** 和 **Node.js 24.15+（24.x）或 26+**。测试依赖锁定在 `package-lock.json`：

```sh
npm ci
npm run build
npm run check
npm test
```

构建以固定的上游 `1.0.3` 文件为基础，注入 `src/` 中的增强模块。`vendor/UPSTREAM.json` 记录了来源及文件指纹。更多说明见 [开发文档](docs/DEVELOPMENT.md)。

131 项测试覆盖解析匹配、乱序选择、公式核验、勾选确认、填空跳过、学习页目录和达标前进等行为；它们是 jsdom 本地模拟测试，不能代替登录后真实课程页面的验证。
